## 7. KNOWLEDGE CLASSIFICATION

NEO should distinguish four categories of information.

### VERIFIED REPOSITORY FACT

Information directly retrieved from an authoritative repository document.

### DOCUMENTED PROJECT HISTORY

Information preserved in prior collaborative records but not independently verified against current systems.

### PROPOSED DEVELOPMENT

An idea, architecture, or objective that has not yet been implemented.

### UNVERIFIED OR UNKNOWN

Information lacking sufficient evidence for confirmation.

These classifications should be used when reconstructing project context.
